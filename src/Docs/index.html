2Word Embeddings
Each word is a vector of 16 numbers — initially random, then learned.

Instead of a dictionary saying "excellent = +1.0", the network starts with random numbers for every word and adjusts them through training. Words used in positive reviews drift towards similar positions in 16-dimensional space.

// 487 words × 16 dimensions = 7,792 learnable values wordEmbeddings = new double[487, 16];
3~8,000 Parameters
The entire network is tiny by modern standards.

Word embeddings: 7,792 values. Input→Hidden weights: 204. Hidden→Output weights: 39. Total: under 70KB. For comparison, BERT has 110 million parameters.

2Tokenisation
Split text into lowercase words, removing punctuation.

3Look Up Word Embeddings
Each token maps to a 16-dimensional vector. Unknown words use the <UNK> token.
4Average Embeddings
All word vectors are averaged into a single 16D sentence vector (Continuous Bag of Words).
5Forward Pass Through Network
The sentence vector passes through the hidden layer (12 neurons, sigmoid activation) then to the output layer (3 neurons).
